# Anno Large Language Model Translator

A **local LLM-powered translator** for Anno language files.

The translator reads an `texts_{LANGUAGE}.xml` file and generates translations for all enabled target languages. Everything runs locally using a compatible PyTorch installation and does not require an online translation API.

## Features

* 🖥️ Runs locally
* 🤖 Uses a Large Language Model for translation
* 🌍 Translates `texts_{LANGUAGE}.xml` into multiple languages
* ⚙️ Languages can be enabled/disabled through the GUI
* 🚫 No external translation API required
* 🐍 Python 3.12 or newer
* 🎮 Supports GPU acceleration through the appropriate PyTorch build

---

## Requirements

* **Python 3.12 or newer**
* PyTorch
* A compatible GPU is recommended for faster translation

CPU-only operation is also possible, although translation will generally be considerably slower.

## Installation

### 1. Clone or download the repository

Download the project and open a terminal in the project directory.

### 2. Create a virtual environment

A virtual environment is **recommended, but not required**.

```bash
python -m venv .venv
```

### 3. Activate the virtual environment

#### Windows

```powershell
.venv\Scripts\activate
```

#### Linux / macOS

```bash
source .venv/bin/activate
```

You should now see `(.venv)` at the beginning of your terminal prompt.

### 4. Install the dependencies

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### PyTorch installation

If `pip install -r req-{GPUVARIANT}txt` fails because the required PyTorch wheel is not available for your Python/platform combination, install PyTorch separately.

For example, for a CUDA 12.4 NVIDIA installation:

```bash
pip install torch --index-url https://download.pytorch.org/whl/cu124
```

After installing PyTorch, run:

```bash
pip install -r req-{GPUVARIANT}txt.txt
```

again.

> **Note:** The PyTorch installation command depends on your hardware and CUDA/ROCm configuration. Use the appropriate PyTorch build for your system.

## Usage

Start the program, with the GUI open your desired `texts_{LANGUAGE}.xml`, it will parse over it already once at this point. Look for parse errors, and fix your XML-Code.

EXAMPLE: `</br>` is not a valid XML expression!

Select an Output-Directory. All Contents that are not the source.xml will be overwritten without further questioning!

Start the Translation.

---

## Language Selection

This pogram uses NLLB-200 for its tranlsations. All 200 languages CAN be configured and used, by default it only uses the languages needed for Anno 1800.

There is no saved configuration so you have to adjust your desired output everytime you start the application.

---

## Output

The translated files are generated by the script in the configured output location.

The original `texts_{LANGUAGE}.xml` is used as the source and is not modified.

## GPU Acceleration

GPU acceleration is strongly recommended when translating large files.

Different builds of PyTorch are required depending on the GPU platform.

| Platform | PyTorch backend |
| -------- | --------------- |
| NVIDIA   | CUDA            |
| AMD      | ROCm            |
| Intel    | XPU             |

The project also provides separate dependency configurations for different hardware platforms where applicable.

For example:

```text
req-nvidia.txt
req-rocm.txt
req-xpu.txt
req-cpu.txt
```

Install the dependency file corresponding to your hardware:

```bash
pip install -r req-nvidia.txt
```

or:

```bash
pip install -r req-rocm.txt
```

or:

```bash
pip install -r req-xpu.txt
```

or:

```bash
pip install -r req-cpu.txt
```

## Troubleshooting

### `pip install -r req-{GPU}.txt` fails

First make sure you are using Python **3.12 or newer**:

```bash
python --version
```

Then upgrade pip:

```bash
python -m pip install --upgrade pip
```

If the problem is related to PyTorch, install the appropriate PyTorch build for your hardware manually before installing the remaining dependencies.

### The translator is very slow

Translation using an LLM can be computationally expensive.

If possible, use a supported GPU build of PyTorch rather than the CPU version.

### PyTorch cannot find the GPU

Check that PyTorch can see your accelerator:

```bash
python -c "import torch; print(torch.__version__); print(torch.cuda.is_available())"
```

For NVIDIA/CUDA, `True` indicates that CUDA is available to PyTorch.
